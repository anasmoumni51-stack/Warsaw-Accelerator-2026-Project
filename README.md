# Warsaw Accelerator 2026 — Salon Explorer

Full-stack application for exploring Warsaw hair/beauty salons. Built as a take-home task for the SumUp Accelerator Software Engineer Intern position.

## Project Structure

```
warsawACC/
├── data-collection/   — TypeScript scripts: collect, validate, seed salon data
├── salon-api/         — Spring Boot REST API (coming soon)
├── salon-ui/          — React Vite frontend (coming soon)
└── README.md
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Data Collection | TypeScript, Google Places API, pnpm |
| Backend | Java, Spring Boot, PostgreSQL |
| Frontend | React, Vite, TypeScript |
| Database | PostgreSQL (AWS RDS) |
| Deployment | Docker, Dokploy |
